Anodizing pictures: copy your photos into this folder, then git add / commit / push.
They appear on the Anodizing service page and on the homepage automatically.
Name each file with what it shows, for example:
  gold-anodized-aluminium-handles.jpg
  black-anodizing-tank-line.jpg
  anodized-door-handles-bulk-order.jpg
(The file name becomes the picture description for Google.)
Resize first: width 1600px max, JPG, under 400 KB each.
